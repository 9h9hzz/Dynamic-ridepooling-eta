# Portfolio release boundary

## Safe to publish after review

- High-level system architecture and research motivation.
- Sanitized interfaces for rolling-horizon simulation.
- A generic trip-vehicle integer assignment example.
- Residual-target construction and feature definitions.
- Self-authored model components with verified provenance.
- A small synthetic example dataset.
- One to three representative, manually cleared figures.
- Qualitative findings without complete result tables.

## Keep private during review

- Full manuscript and presentation files.
- Exact submission title and identifying metadata.
- Complete simulation, routing, and shareability-shadow implementation.
- Full parameter tables if they enable paper reproduction.
- Raw or licensed network and request data.
- Generated daily passenger datasets.
- All experiment scripts, checkpoints, seed-level outputs, and transfer matrices.
- Full ablation, feature-importance, duration-stratified, and rejection-rate result sets.
- Third-party repositories copied into the working directory.

## Recommended first public release

Release the README, safe code examples, synthetic data, and one architecture graphic. Add exact experimental figures only after written clearance.
