# Public figures

Only manually cleared figures belong in this directory.

Recommended first-release figures:

1. a high-level optimization-and-learning workflow;
2. a conceptual ETA residual diagram without final metrics;
3. at most one representative result figure after supervisor/venue clearance.

Use filenames beginning with `public-` for approved PNG files. The `.gitignore` blocks other PNGs by default to reduce accidental release of manuscript figures.
